# Research Overview

Question: separate covariance sampling error from failure to track changing
covariance. Test whether a simple spectral cleaner helps estimation and
long-only allocation, rather than assuming that a cleaner spectrum helps both.

The first release is synthetic only, with known future covariance used strictly
for evaluation. The experimental design is fixed before inspecting outcomes.
Default scenarios, windows, and seeds are in the CLI and results manifest.

Scope excludes real-market performance, optimal shrinkage claims, new proofs,
and reuse of an existing project's code or results.
